Overview

A two-page example. Comments anchor per page, and the export groups them under the page labels set in comments-config.js.

This page defines a small design system in theme.css — an accent color, fonts, surfaces. The comment layer reads those same tokens, so its highlights and popovers match the page. Nothing about the layer was restyled to make that happen.

Comment on this page

Select this sentence and leave a note. Then go to the Anchoring page and leave another. Each comment stays on the page where you made it, because a thread records which page it belongs to alongside the quoted text.

Then export

Click Export in the header. The Markdown you get back has a section per page, in the order declared in the config, with the nearest heading shown above each quote. That structure is what makes the export easy to hand to Claude for triage.
